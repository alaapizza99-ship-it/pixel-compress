# PixelCompress
Flutter photo compressor / resizer / cropper / blur / converter (JPG, PNG, WEBP, HEIC, PDF).
Built to APK + AAB by GitHub Actions - no Android Studio needed.

- `.github/workflows/build-apk.yml`  builds APK + AAB on every push
- `.github/workflows/create-keystore.yml`  run once to create the Play upload key
- `privacy-policy/index.html`  host in a separate public repo (GitHub Pages)
- `play-assets/`  store icon, feature graphic, store listing text
